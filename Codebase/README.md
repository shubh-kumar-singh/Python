# 🛒 Shopping Cart System

A simple console-based **Shopping Cart System** developed using Python. This project allows users to view available products, add products to their cart, remove items, calculate the subtotal, apply discounts, and generate a final bill including GST.

## 🚀 Features

- **View Products:** Display all available products with their prices.
- **Add to Cart:** Add products and specify quantities.
- **Remove from Cart:** Remove products from the shopping cart.
- **View Cart:** Display selected products, quantities, and subtotal.
- **Discount System:** Automatically apply a 10% discount when the subtotal exceeds ₹500.
- **GST Calculation:** Calculate 18% GST on the discounted amount.
- **Checkout:** Generate a final bill with a detailed price breakdown.
- **Exit:** Safely exit the application.

```bash

```

## 🧾 Billing System

The application calculates the final bill using the following rules:

- **Subtotal:** Total price of all selected products.
- **Discount:** 10% discount if subtotal is greater than ₹500.
- **GST:** 18% GST on the amount after discount.
- **Grand Total:** Discounted amount + GST.
